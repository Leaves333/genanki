# genanki
helps with sentence mining from visual novels

only looks stuff up from jisho, doesn't support j-j dictionaries yet

create a file named `list.txt`, insert alternating lines of sentences and words

demo: https://www.youtube.com/watch?v=XeyG_E77cUM

## using the software

clone the github repo, install needed libaries, and run the code
```bash
git clone https://github.com/Leaves333/genanki.git
pip install genanki jisho_api
cd genanki
python main.py
```
